# Capture-quality gate contract

`capture_gate_vectors.json` is the language-neutral fixture set for the
deterministic document capture-quality gate. Every MCP server implementation
must return the same verdict and the same five signals for the same capture, so
a client can gate a photo before upload against any server without changing its
logic. Vectors are generated by
`python/scripts/generate_capture_gate_vectors.py`; do not hand-edit them.

## Verdict contract

```text
RETAKE | REVIEW | PASS
```

- **RETAKE** — the capture is not usable (too dark, blank, or unreadably
  blurry). Re-take before uploading.
- **REVIEW** — borderline (dim, washed out, scant content, mild blur). Flag
  for a human instead of silently rejecting a readable capture.
- **PASS** — readable as far as this gate can tell.

The gate answers "is the capture readable?", never "is this the right
document?". Content verification (`MATCH | REVIEW | MISMATCH |
NO_SOURCE_DATA`) is a separate contract.

## Signals

| Signal | Meaning |
|---|---|
| `sharpness` | Mean gradient magnitude inside a 1px dilation of the ink mask |
| `contrast` | `p90(luma) - p25(ink pixels)` (whole-frame percentiles when ink is too sparse) |
| `ink_ratio` | Fraction of ink pixels: `luma < p90(luma) - 0.25` |
| `brightness` | Mean luma |
| `exposure` | `abs(brightness - 0.5)` |

Ink coverage is measured where the content is. A whole-frame gradient
average is diluted by the paper background, and whole-frame contrast
percentiles break when ink covers fewer pixels than the percentile.

## Measurement grid and thresholds

Every capture is converted to luma and resampled bilinearly to a fixed grid
(max side **512**, aspect preserved) before measuring. Thresholds therefore
transfer across camera resolutions.

| Verdict | Gate |
|---|---|
| RETAKE | `brightness < 0.10` |
| RETAKE | `ink_ratio < 0.002` |
| RETAKE | `sharpness < 0.08` (only when `ink_ratio >= 0.002`) |
| REVIEW | `brightness < 0.25` |
| REVIEW | `contrast < 0.18` |
| REVIEW | `ink_ratio < 0.003` |
| REVIEW | `sharpness < 0.13` (only when `ink_ratio >= 0.003`) |
| PASS | none of the above |

The `0.08–0.13` sharpness band is the supervised "readable blur" band: real
field captures can stay legible there, so they are flagged for a human rather
than rejected.

## Conformance

Fixtures are PNG so every decoder sees identical pixels. Each case records
the expected verdict, the exact reason strings, and the five signals.

- Verdict and reasons must match exactly.
- Signals must match within `signal_tolerance` (`5e-4`).

Implementations:

- Python — `python/tests/test_capture_gate_vectors.py`
- Go — `go/tools/capture_gate_test.go` (`TestGoldenVectors`)
- Java / Rust — not ported yet; load the same file when they are.

The gate must stay deterministic and offline: fixed arithmetic only, no LLM,
no trained model, and no neural-network or CV library in the inference path.
